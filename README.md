# Resolve — Student Grievance & Representative Redressal Portal

A full-stack web application designed for college environments to streamline communication between Class Representatives (CRs) and Administrators, ensuring transparent issue tracking and institutional accountability.

## 🚀 Key Features
- **Role-Based Access Control (RBAC):** Distinct dashboards and secure workflows for Class Representatives and Administrators.
- **Dynamic Ticket Lifecycle:** Raise priority-based class concerns with enforced character validation, live status tracking (*Pending, In Progress, Resolved*), and status-locking mechanisms.
- **Real-Time Notification System:** Dynamic read/unread notification tracking linked to admin responses.
- **Official PDF Reporting:** Automated, print-ready institutional reporting module styled for principal review (Mailam Engineering College template) complete with department statistics and sign-off blocks.

## 🛠️ Tech Stack
- **Backend:** Java, Spring Boot, Spring Data JPA
- **Frontend:** Thymeleaf, Tailwind CSS, HTML5
- **Database:** MySQL
